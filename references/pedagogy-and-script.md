# 教学设计、口播文案与 `script.json` 规范

---

## 一、核心教学红线（不可违反）

### 1. 独立成课：题干与教材定义必须 100% 写全
- **每道例题**在画面上必须同时具备：
  1. `教材例 X`（或 `教材习题 X-X 第 Y 题`）标签，方便对照原书查阅；
  2. **完整原题干**：明确写出「问什么」（如「判断下列集合是否为……」「求该方程组的通解」「证明……」），以及**全部已知条件、公式/矩阵/数据数值、变量范围**（如 `$x \in \mathbb{R}$`、`$n \ge 2$`）。
  3. 严禁缩写或省略题干，确保**没有实体书的观众也能完全独立看懂**。
- **每个教材定义、定理、推论**必须写全完整前提条件与结论（如非空、连续/可导、满秩/可逆、独立性等限定词），不得为了省字删掉关键前提。

### 2. 分步动态演算：严禁画面静止干读
- 口播讲到消元、代入、填位、推导、展开、证明步骤时，画面必须用 `self.pace_to(seg, frac)` 与口播**一一同步动起来**，逐行或逐卡片呈现中间算式与结果。
- 严禁把一整道复杂例题一次性静态铺满页面，然后口播干读几十秒。
- **先具体、再抽象**：遇到高阶/抽象定理或一般公式时，先用低阶具体数值例子一步步演示，再推广到一般 $n$ 阶/抽象结论。

### 3. 单集 5~6 幕结构（目标 4 ~ 6 分钟，直觉 4 : 应试 6）
1. **破冰 / 脉络定位**：
   - **每章第一集**：开场展示全书章节进度路线图 `make_knowledge_map(BOOK_CHAPTERS, highlight_idx=章序号)`（0-based）。
   - **章内其余各集**：使用「干净封面标题 + 核心概念对比卡」，不再重复放全书路线图。
2. **核心直觉 / 定义引入**：几何或物理/现实直觉 + 严密教材定义。
3. **核心性质 / 定理 / 计算法则**：卡片化拆解 + 先具体后抽象推导。
4. **教材经典例题实战**（2~3 题）：完整题干 + 分步动态演算。
5. **高频考场避坑 / 反例警示**：针对最易错的 2~3 个点给出明确反例与判别口诀。
6. **一屏速通卡（建议截图）+ 下集预告**：浓缩全节公式与步骤，自然衔接下一节。

## 二、配音、字幕与文案规范

1. **统一配音配置**：
   - 默认 `"voice": "zh-CN-YunxiNeural"`，`"rate": "+8%"`（沉稳清晰的讲师节奏；可在新书初始化时自定义）。
2. **100% 逐字同步字幕**：
   - `script.json` 中**只写 `text` 字段，不写缩写 `subtitle`**。
   - `scripts/tts_gen.py` 自动根据 `text` 按标点切分、按字数权重分配时长，仅收紧 `A B` → `AB` 等 TTS 朗读空格，保证“听到什么就看到什么”。
3. **平实讲师口吻（去 AI 味）**：
   - 准确、干练、自然，像优秀大学讲师面对面讲解。
   - **严禁浮夸网感/AI 腔词句**，例如：“降维打击、刻进 DNA、神级反例、切豆腐、算到手抽筋、穿袜子穿鞋、奇迹发生了、解锁神技、秒杀、天花板、直接起飞”等。
4. **防 TTS 粘连与错断句**：
   - 列举数字之间必须用顿号 `、` 分隔（如 `1、0、0`，切勿用空格隔开数字导致字幕粘成 `100`）。
   - 长主语或长列举后主动补逗号引导换气（如“求逆、求秩、解方程组，全都要用到它”）。
   - 希腊字母或易错读数学符号在 `text` 中用中文音译或清晰表达（如 `阿尔法`、`贝塔`、`λ` 写 `拉姆达`、`x^2` 写 `x 的平方`），避免 TTS 漏读或误读。
5. **段尾停顿（`pause_after`）**：
   - 普通段落：`0.45` ~ `0.50`
   - 切幕过渡：`0.55` ~ `0.60`
   - 片尾总结：`0.60` ~ `1.00`

## 三、`script.json` 字段说明

```json
{
  "episode_id": "ep01",
  "title": "1-1 章节标题",
  "output_name": "EP01_1-1_章节标题",
  "scene_name": "Ep01TopicSlug",
  "voice": "zh-CN-YunxiNeural",
  "rate": "+8%",
  "segments": [
    {
      "id": "s01_intro",
      "chapter": 0,
      "pause_after": 0.45,
      "text": "欢迎来到……"
    }
  ]
}
```
- `output_name`：决定输出 `.mp4` 与 `.srt` 的文件名。
- `scene_name`：必须与 `scene.py` 中 `SyncedScene` 子类名完全一致。
- `segments[].id`：必须与 `scene.py` 中 `with self.segment("...")` 的参数一一对应且顺序一致。
